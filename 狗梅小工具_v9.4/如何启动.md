# 🐶 狗梅小工具 — 启动指南

## 环境要求

- **Python 3.9+**（推荐 3.9~3.12，3.14 暂不支持 onnxruntime）
- **操作系统**：macOS / Windows / Linux

---

## macOS 快速启动

### 第一步：安装依赖

打开终端，进入工具目录：

```bash
cd ~/Desktop/狗梅小工具_v9.4
```

安装 Python 依赖：

```bash
pip3 install gradio numpy opencv-python opencv-contrib-python Pillow
```

安装 onnxruntime（用于 AI 分割模型）：

```bash
pip3 install onnxruntime
```

> 注意：如果你的 Python 版本是 3.13+，onnxruntime 可能无法安装。建议使用 Python 3.9~3.12。

### 第二步：启动

**方式一：命令行启动**

```bash
cd ~/Desktop/狗梅小工具_v9.4
python3 app.py
```

**方式二：双击启动脚本**

```bash
chmod +x 启动.sh
./启动.sh
```

**方式三：使用启动器（自动打开浏览器）**

```bash
python3 launcher.py
```

### 第三步：使用

启动后终端会显示：

```
Running on local URL: http://0.0.0.0:7860
```

打开浏览器访问 **http://localhost:7860** 即可使用。

---

## Windows 快速启动

### 第一步：安装 Python

下载并安装 Python 3.10+：https://www.python.org/downloads/

> 安装时**勾选 "Add Python to PATH"**

### 第二步：安装依赖

打开 cmd 或 PowerShell：

```cmd
cd Desktop\狗梅小工具_v9.4
pip install gradio numpy opencv-python opencv-contrib-python Pillow onnxruntime
```

### 第三步：启动

```cmd
python app.py
```

或双击 `launcher.py` 文件。

浏览器访问 **http://localhost:7860** 即可使用。

## 常见问题

### Q: 启动后报错 "No module named 'gradio'"
A: 没装依赖。运行 `pip3 install -r requirements.txt` 安装。

### Q: 报错 "No module named 'cv2.ximgproc'"
A: 需要安装 opencv-contrib-python：`pip3 install opencv-contrib-python`

### Q: 报错 "Decompressed data too large for PngImagePlugin"
A: 这是 AI 生成的 PNG 图片 metadata 太大导致的，程序已内置修复。如果仍然报错，请更新到最新版本。

### Q: 处理很慢
A: AI 分割模型推理需要几秒时间，属正常现象。搜索窗口越大处理越慢，建议不超过 20。

### Q: 端口 7860 被占用
A: 可能有其他程序占用了该端口。在 macOS 上运行 `lsof -ti:7860 | xargs kill -9` 杀掉占用进程。

### Q: onnxruntime 安装失败
A: onnxruntime 目前只支持 Python 3.9~3.12。如果你的 Python 版本更高，程序会尝试调用系统 Python 3.9 来运行分割脚本。
