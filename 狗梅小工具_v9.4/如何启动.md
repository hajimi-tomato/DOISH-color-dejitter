# 狗梅小工具 · 安装、启动和打包

## 环境

推荐 64-bit Python 3.10–3.12，Windows / macOS / Linux。基础处理在 CPU 上运行，无需 CUDA。依赖固定 Gradio 6.31.0、ONNX Runtime 1.20.1，其他包有兼容范围；升级依赖后应重新跑测试。

只安装一个 OpenCV 包：`opencv-python-headless` 已包含本项目使用的 NL-Means 和 `edgePreservingFilter`。不要同时安装 `opencv-python`、`opencv-contrib-python` 与 headless 版本。

## 从仓库根目录手动启动

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe "狗梅小工具_v9.4/launcher.py"
```

macOS / Linux：

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python "狗梅小工具_v9.4/launcher.py"
```

也可执行 `python 狗梅小工具_v9.4/app.py`，然后手动打开 <http://127.0.0.1:7860>。`launcher.py` 会自动开浏览器。

## 一键脚本

- Windows：双击工具目录内的 `启动.bat`。
- macOS/Linux：`bash 狗梅小工具_v9.4/启动.sh`。

首次会在工具目录创建 `.venv` 并安装依赖，成功后创建安装标记。升级项目依赖时，请手动用该环境执行 `python -m pip install -r requirements.txt`，或只删除 `.venv/doish-ready-v1` 标记，让脚本下次重试安装。无需修改全局 Python。

## 分割模型

普通 H/S 降噪及不统一背景的 V 降噪都无需模型。使用背景功能时，点击界面中的「下载 / 校验分割模型」，或者：

```bash
python "狗梅小工具_v9.4/download_model.py"
```

原始下载地址：[skytnt/anime-seg/isnetis.onnx](https://huggingface.co/skytnt/anime-seg/resolve/main/isnetis.onnx)。手动下载后放到 `狗梅小工具_v9.4/models/isnetis.onnx`，再运行下载脚本校验已有文件。

SHA-256：

```text
f15622d853e8260172812b657053460e20806f04b9e05147d49af7bed31a6e99
```

文件约 176 MB / 168 MiB。下载失败保留原有文件，不安装未通过校验的新文件；重试会重新下载。上游权重变化导致哈希不匹配时，需要维护者核实，不能忽略校验。

模型使用当前 Python 环境内的 ONNX Runtime，不再调用 `/usr/bin/python3`。加载一次后复用会话，蒙版缓存最多 4 张且合计不超过 32 MiB。缺失、损坏或依赖错误会在处理状态明确提示。

## 路径和端口

- 模型默认在工具 / exe 旁的 `models/isnetis.onnx`。可通过 `DOISH_MODEL_PATH` 指定完整模型路径。
- 自定义预设默认在 `runtime/presets.json`。`DOISH_DATA_DIR` 可指定用户数据目录，适合安装目录只读的场景。
- 默认只监听 `127.0.0.1`，不创建 Gradio 公网分享链接。浏览器中的图片操作都发给本机服务。
- 端口冲突时使用 `python launcher.py --port 7861`，不要结束其他不相关程序。
- 如确需局域网访问，可显式传入 `--host 0.0.0.0`；当前工具无账户认证，默认本机模式适合个人使用。

## Windows 打包

在已激活的独立环境、仓库根目录：

```powershell
python -m pip install -r requirements-dev.txt
python "狗梅小工具_v9.4/build_windows.py"
```

或双击工具目录内的 `build_windows.bat`。产物：

```text
狗梅小工具_v9.4/dist/DOISH/
├── DOISH.exe
└── _internal/   # 不可删除；包含 Python、依赖及前端资源
```

需要分发整个目录。模型默认不捆绑，在界面下载后会保存为 `DOISH/models/isnetis.onnx`。可用 `DOISH.exe --no-browser --port 7861` 启动。GitHub Actions 也提供 Windows 目录版构建产物。

## 常见问题

**依赖安装失败 / Python 版本不兼容**：使用 64-bit Python 3.10–3.12，确保 pip 属于当前虚拟环境，不要把系统 Python、conda 和虚拟环境的包混用。

**ONNX Runtime DLL 加载失败**：先确认使用项目固定依赖；Windows 还需要可用的 Microsoft Visual C++ 运行库。请从微软官方安装或修复对应运行库。界面会跳过背景统一，普通降噪可继续使用。

**模型下载失败**：手动从官方地址下载，再运行校验脚本。没有模型也可关闭背景统一继续使用。

**PNG 元数据过大**：程序支持比 Pillow 默认上限更大的 AI 参数，但仍有 16 MiB/64 MiB 限制；超限请先用图像工具移除不必要的文本块。

**高分辨率处理慢**：先减小搜索半径，关闭 S 或 V。NLM 使用带重叠上下文的分块，输出不会缩小；其他处理仍会使用整图内存。

**预设文件损坏**：程序保留原文件并提示路径。先备份该文件再修正 JSON 或改名；程序会在下次保存时创建新文件。

## 验证

```bash
python -m pytest -q
```

自动测试不下载模型、不连接外网。真实 ONNX 推理及便携包运行应额外验收；浏览器端还应检查上传/粘贴、分割线、缩放、平移、HSB 和下载。
