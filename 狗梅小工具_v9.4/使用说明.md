# 🐶 狗梅小工具 v9.4 — 使用说明

## 这是什么？

狗梅小工具是一款 **AI 绘画色彩去抖动工具**。

AI 生成的图像在同一色彩区域内常常存在色相级别的随机抖动——肉眼看可能不明显，但放大观察、提高饱和度、做后期调色或打印时就会暴露。狗梅小工具通过智能算法消除这些色彩噪声，让画面更干净、色彩更统一。

---

## 核心功能

### 1. NL-Means 色度降噪
在 Lab 色空间只对色度通道（a/b）做非局部均值降噪，**亮度通道（L）不动**。
- 只消除色彩噪声，完全不损失亮度细节（纹理、笔触、光影）
- NL-Means 在全图搜索相似块做加权平均，天然保边

### 2. 保边滤波色度平滑（可选）
使用 `edgePreservingFilter` 在频域做保边滤波：
- 平坦区域强力平滑（把残余色差抹平）
- 边缘处保持锐利（不跨颜色边界）
- 只作用于色度通道，亮度不受影响

### 3. AI 前景/背景分割 + 背景纯色化
使用 `anime-segmentation` 模型（ISNet 架构）分割前景和背景：
- **纯色背景**：自动检测后统一为纯色（L/a/b 全部替换为均值）
- **复杂背景**：不做纯色化，只做降噪
- 前景/背景边界做平滑过渡，无硬边

## 界面说明

### 左侧面板

| 区域 | 说明 |
|---|---|
| 📋 预设配置 | 选择/保存/删除参数预设 |
| 📥 上传图片 | 上传或粘贴图片 |
| 🎚️ 整体强度 | 最终结果与原图的混合比例（0=不修正，100=全力修正） |
| 🔴 色相修正 (H) | **核心参数**。"去噪阈值"=色度降噪强度，"平滑半径"=搜索窗口大小 |
| 🟡 饱和度修正 (S) | 控制保边滤波。启用后对色度做额外的保边平滑 |
| ⚪ 明度修正 (V) | 控制背景纯色化强度 |
| ⚙️ 高级设置 | "边缘保护强度"=NL-Means 模板窗口，"低饱和度跳过阈值"=低饱和区域保护 |

### 右侧面板

| 区域 | 说明 |
|---|---|
| 📊 前后对比 | 左=原图，右=修正后。支持滚轮缩放、拖拽平移、双击重置 |
| 🎨 色相/饱和度预览 | 调整 HSB 放大观察修正效果差异（不影响实际输出） |
| 🔍 差异图 | 被修正的部分高亮显示（放大 5 倍） |
| 📥 下载区域 | 处理完成后自动显示修正后图片和差异图的下载链接 |

## 参数调整建议

### 色度降噪强度（"去噪阈值"滑块）
这是最重要的参数：
- **6~10**：轻度降噪，适合高质量图片
- **10~15**：中度降噪，适合大多数 AI 生成图
- **15~20**：强力降噪，适合噪声明显的图片
- **>20**：极强降噪，可能丢失微妙的色彩变化

### 搜索窗口（"平滑半径"滑块）
- 越大效果越好但速度越慢
- 推荐 10~15，不建议超过 20

### 整体强度
- 如果修正后效果过重，降低整体强度即可
- 推荐 70~90

---

## 注意事项

1. **处理时间**：因为使用了 AI 分割模型，每张图处理需要 5~15 秒（取决于图片大小）
2. **图片格式**：支持 PNG、JPG、WebP 等常见格式
3. **大图片**：支持高分辨率图片，但处理时间会更长
4. **PNG metadata**：支持读取包含大量 AI 生成参数的 PNG 文件
5. **S/V 通道**：启用"饱和度修正"和"明度修正"会增加额外处理步骤，建议按需开启
