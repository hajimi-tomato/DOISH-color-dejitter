# 狗梅小工具 v9.4 · 使用说明

## 推荐流程

1. 上传 PNG、JPEG、WebP 等静态图片；也可以展开剪贴板入口粘贴图片。需要保留 ICC 或 PNG AI 参数时请用文件上传。
2. 先选择「默认」或「轻度修正」。选择预设会载入参数，点击「开始处理」才应用。
3. 在右侧拖动分割位置比较原图与结果。滚轮缩放，拖动平移，双击或点击「适应窗口」复位。聚焦预览后按 `0` 也可复位。
4. 如果想检查微弱杂色，展开 HSB 观察工具，提高饱和度。左右两侧使用相同观察设置，导出不受影响。
5. 在下载区保存 `_clean.png` 与 `_diff.png`。差异图把 RGB 绝对差放大 5 倍，不是颜色准确性的评分。

## 参数的实际含义

所有“比例”和整体强度采用 **0–1**，不是 0–100。保留 H/S/V 旧标签方便使用，但 H/S 是 Lab 色度操作，不是分别锁定 HSV 的 H 和 S。

| 组 | 参数 | 实际行为 |
|---|---|---|
| 整体 | 整体强度 | 最后对全图与原图混合；0 像素不变，1 完整应用处理 |
| H | 去噪阈值 | Lab a/b 的 NL-Means `h`；0 关闭 H，6–10 轻度，10–15 中度，越大越容易抹掉细微色差 |
| H | 搜索半径 | 相似块搜索窗口为 `2 × 半径 + 1`；范围 1–30，建议 10–15 |
| H | 色度修正比例 | 将色度降噪结果混入的比例；0 不做 H 修正 |
| H | 软阈值 | 开启时对大色差渐进减弱修正；关闭时超过保护阈值的改动被跳过 |
| S | 启用开关 | 开启额外的保边色度平滑，默认关 |
| S | 平滑半径 | 控制保边滤波的空间范围 |
| S | 色差阈值 | 控制滤波的颜色容差及大色差保护；0 不做 S 修正 |
| S | 修正比例 | S 平滑结果的混入比例；0 不生效 |
| S | 软阈值 | 渐进保护或硬性跳过较大的色度改动 |
| V | 启用开关 | 开启亮度 NL-Means，并允许按需统一背景；默认关 |
| V | 搜索 / 柔边半径 | 控制亮度搜索范围及背景蒙版过渡宽度 |
| V | 去噪阈值 | 控制亮度降噪及保护阈值；0 不做 V 和背景修正 |
| V | 修正比例 | 同时控制亮度和背景纯色化的混入比例；0 两项均不生效 |
| V | 软阈值 | 对较大亮度/背景改动使用渐进保护，关闭时使用硬阈值 |
| V | 同时统一背景 | 需要 V 开启及模型就绪；关闭后只做亮度降噪，不运行分割 |
| 高级 | 边缘保护 | 映射到 3/5/7/9/11 像素的 NL-Means 模板；不是万能“保边百分比” |
| 高级 | 低饱和度保护 | 对低饱和和暗部的色度修正减弱；不阻止显式开启的亮度修正 |

H/S 在浮点 Lab 工作空间中保留 L，但色域裁切和 8-bit 输出舍入仍可能造成微小亮度变化。降噪也可能删除真实的颜色细节，不能保证“不损失任何细节”。

## 背景处理

分割模型只在 V 开启、V 阈值及强度非零、且背景统一开启时加载。模型加载后复用会话；相同图片的蒙版有上限缓存。

背景是否接近纯色，根据**处理前原图**判断：全局波动较小，且多个空间区域的颜色中位数一致才允许统一。浅渐变、阴影、纹理或可用背景太少时跳过。处理状态会说明实际结果。

纯色化也服从整体强度；背景不会再绕过整体混合。想得到最强统一效果，可使用 V 比例 1、整体强度 1，并关闭 V 软阈值；务必检查边缘和背景。默认较保守。

模型缺失或无法加载时会明确提示，保留 H/S/V 滤波结果；不会声称 AI 分割已经成功。关闭背景统一后可完全不使用模型。

## 预设

| 预设 | 用途 |
|---|---|
| 默认 | 只做中等比例的色度降噪；S/V 关闭 |
| 大狗叫 | 更强色度降噪，开启 S/V 与背景统一 |
| 轻度修正 | 较低色度阈值、比例及整体强度 |
| 强力去噪 | 强色度降噪与轻度亮度降噪，不统一背景 |
| 全通道修正 | H/S/V 全开，使用保守的默认强度 |
| 耄耋哈 | 强 H/S/V；可能损失渐变和细节，建议逐项对比 |

输入新名称并点击「保存预设」即可持久化；同名自定义预设会更新。内置预设不能覆盖、不能删除。删除自定义预设后恢复默认参数。文件损坏时会保留原文件并提示，不会静默覆盖。

更改参数或预设后，旧结果仍可用于观察，但下载入口会清空，处理状态会提醒重新处理，避免误下载旧参数结果。

## 图片与输出

- 导出 PNG，尺寸不变；alpha 原样保留，完全透明像素不参与背景统计，也不修改其 RGB。
- 应用 EXIF 方向。ICC 输入转换为 sRGB；输出附带对应 sRGB 配置。无法识别的 ICC 会报错，避免无提示错色。
- 保留 PNG 文本（如 `parameters`、workflow），单文本解压上限 16 MiB、总计 64 MiB；不是无限解除安全限制。
- 最大 3200 万像素、100 MiB。浏览器仅使用最长边 1600 px 的预览，HSB 只在预览中计算。
- 当前算法和导出为 8-bit。已识别的高位深灰度输入明确拒绝；高位深彩色图片也不应作为无损高位深工作流使用，请先自行转成 8-bit sRGB。
- 临时结果在当前服务运行期间可下载；关闭程序可能清理临时文件，请及时保存。自定义预设会持久保存。
- 不承诺固定秒数；分辨率、搜索窗口、S/V 开关及 CPU 都会影响耗时。初次模型加载更慢，后续复用更快。
